STM32F103C8T6 + ADXL345 + OLED 0.91" 128x32

README: прошивка и работа проекта

Инструкция рассчитана на Windows: проект можно распаковать в любую удобную папку, без привязки к абсолютным путям автора. Основной вариант прошивки - через ST-Link V2. USB-UART через встроенный загрузчик STM32 описан ниже как запасной вариант.

Коротко

  1. Установить PlatformIO Core или VS Code + PlatformIO IDE.
  2. Распаковать проект в папку без кириллицы и пробелов, например stm32-oled.
  3. Открыть PowerShell или Terminal в папке проекта.
  4. Подключить ST-Link: SWDIO, SWCLK, GND и питание 3.3V.
  5. Поставить BOOT0 = 0.
  6. Выполнить сборку или прошивку. В platformio.ini ST-Link уже выбран по умолчанию.
pio run
pio run --target upload

Что прошиваем

Камень: STM32F103C8T6.

Основное PlatformIO окружение: stm32-bluepill-f103c8-oled-128x32-stlink, прошивка через ST-Link V2.

Запасное окружение для USB-UART bootloader: stm32-bluepill-f103c8-oled-128x32.

Плата в конфиге PlatformIO: bluepill_f103c8.

Файл прошивки после сборки:

.pio\build\stm32-bluepill-f103c8-oled-128x32-stlink\firmware.bin

Что делает прошивка

  • Читает ADXL345 по I2C на пинах PB7/PB6.
  • Показывает текущее значение X и последний пойманный пик Max на OLED.
  • Ловит локальный максимум сигнала: значение сначала растет, потом проседает на заданный порог.
  • На каждый такой пик один раз мигает светодиод PC13 и один раз печатает максимум в Serial.
X peak max: 3.427

Пороги в коде:

  • PEAK_MIN_RISE - насколько сигнал должен вырасти от нижней точки, чтобы начать считать пик.
  • PEAK_DROP - насколько сигнал должен упасть после вершины, чтобы максимум был зафиксирован.

Подготовка Windows

  1. Установить Python 3 с python.org и отметить галочку Add python.exe to PATH.
  2. Установить PlatformIO Core командой py -m pip install -U platformio или поставить расширение PlatformIO IDE в VS Code.
  3. Открыть терминал именно в папке проекта. Если терминал открыт в другом месте, сначала перейти командой cd /d <путь-к-папке-проекта>.

Проверка, что PlatformIO доступен из терминала:

pio --version

Способ 1: ST-Link V2

Это основной способ для проекта. BOOT0 переключать в режим загрузчика не нужно.

Подключение

ST-Link V2 STM32F103C8T6 Комментарий
SWDIO PA13 / SWDIO Линия данных SWD
SWCLK PA14 / SWCLK Тактовая линия SWD
GND GND Общая земля обязательна
3.3V 3.3V Только если питаешь плату от ST-Link

Положение BOOT для ST-Link

  • BOOT0 = 0
  • BOOT1 = 0, если на плате есть такой джампер

Команды

Так как ST-Link окружение выбрано по умолчанию, можно запускать короткие команды:

pio run
pio run --target upload

То же самое в явном виде:

pio run -e stm32-bluepill-f103c8-oled-128x32-stlink
pio run -e stm32-bluepill-f103c8-oled-128x32-stlink --target upload

Если ST-Link не прошивает

  • Проверь SWDIO, SWCLK, GND.
  • Проверь, что плата получает 3.3V питание.
  • Проверь, что BOOT0 = 0.
  • Попробуй нажать Reset перед командой upload.
Запасной способ: USB-UART через встроенный bootloader

Этот вариант нужен только если ST-Link нет. Понадобится USB-UART адаптер с логикой 3.3V.

Если адаптер не появляется как COM-порт, установи драйвер для его чипа: обычно CH340, CP210x или FTDI.

Подключение

USB-UART STM32F103C8T6 Комментарий
TX PA10 / RX1 Передача адаптера идет в прием STM32
RX PA9 / TX1 Прием адаптера идет с передачи STM32
GND GND Общая земля обязательна
3.3V 3.3V Если питаешь плату от адаптера

Важно по питанию

STM32F103C8T6 работает от 3.3V. Не подавай 5V на питание чипа и не подключай 5V-логические сигналы напрямую к I2C/UART.

Порядок прошивки через UART

  1. Поставить BOOT0 = 1.
  2. Нажать Reset на плате или кратко отключить питание.
  3. Посмотреть порт командой pio device list.
  4. Прошить, указав найденный порт.
  5. Вернуть BOOT0 = 0.
  6. Нажать Reset, чтобы запустить прошитую программу.
pio device list
pio run -e stm32-bluepill-f103c8-oled-128x32 --target upload --upload-port COM3

Вместо COM3 укажи порт, который показала команда pio device list. На Windows это обычно COM3, COM4 или другой номер.

Если UART-прошивка не стартует

  • Проверь, что BOOT0 = 1 именно до Reset.
  • Проверь перекрестное подключение: TX -> PA10, RX -> PA9.
  • Проверь, что адаптер в режиме 3.3V.
  • Закрой Serial Monitor перед прошивкой.

Если нужно сначала только собрать без прошивки:

pio run -e stm32-bluepill-f103c8-oled-128x32

Подключение OLED и ADXL345

Для текущей прошивки используется I2C1:

STM32F103C8T6 OLED 0.91" 128x32 ADXL345
3.3V VCC VCC
GND GND GND
PB7 SDA SDA
PB6 SCL SCL

После прошивки

  • На OLED должно появиться Starting, потом ADXL OK или No ADXL.
  • Если датчик найден, экран показывает X и Max.
  • При каждом локальном максимуме по оси X светодиод на PC13 коротко мигает.
  • В Serial Monitor на каждый пик выводится одна строка X peak max: ....

Диагностика

ST-Link не находится

  • Проверь USB-кабель.
  • Проверь SWDIO, SWCLK, GND.
  • Проверь, что плата получает 3.3V питание.
  • Попробуй нажать Reset перед командой upload.

OLED пустой

  • Проверь питание OLED: VCC и GND.
  • Проверь I2C: PB7 -> SDA, PB6 -> SCL.
  • Типовой адрес OLED: 0x3C.
  • Экран в коде выбран как SSD1306 128x32.

Главная команда

Для нашего проекта и STM32F103C8T6 через ST-Link:

pio run --target upload
